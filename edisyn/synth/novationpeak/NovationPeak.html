Novation Peak

Firmware 2.1

Written by Adam Schabtach. The parameter map was measured on a Peak running firmware 2.1.0.8: every editable parameter was swept over CC/NRPN and confirmed in the patch dump. The editor's parameter tables are generated from that measured map.

This editor never writes to the Peak's memory

It sends only edit-buffer writes (which are lost when you change patch or power off), patch requests and the parameters' CC/NRPN messages. Write to Patch and the librarian's bank writes are disabled. To store a patch, save it to disk and write it with peaktool write <file.syx> --slot D127 --allow-flash-write (from the peak-editor project), which backs up the slot first and verifies the write.

Notes

  • Requesting a stored patch reads it directly by bank and number. No program change is sent, so the Peak's display does not follow the patch shown here. Use Send to Current Patch to hear it.
  • Parameter changes are sent live as CC/NRPN, as the Peak's own panel sends them. Settings that exist only in the Peak's menus (FX matrix, LFO 3/4 wave and rate, arp clock rate, Osc 2 ModEnv2 > Pitch, the patch name) are sent as a whole edit-buffer patch a moment after you stop changing them. The Peak stops any held note when it receives a whole patch, so play the note again after changing one of these.
  • Reverb Type and Size (FX tab, Reverb) are linked on the Peak: choosing a type also sets the size, and the size can move the type. Either one is sent live, then the patch is re-read from the Peak, so both show what the Peak now has. Randomize, hill-climbing and morph never change them.
  • Not editable: Animate 1/2 Hold (no stored value found), user wavetables and global settings. Their stored bytes, and every byte of the patch this editor doesn't model, are kept unchanged.
  • Values the Peak stores outside the documented range (for example Arp Chance 0 in patches from firmware 1.x) are kept as they are and shown as "(raw N)" in menus.
  • Randomize, hill-climbing and morph leave the name, category, genre, tempo, levels, tuning, voice and arp settings alone by default (see Edit Mutable Parameters), and keep at least one oscillator, noise or ring level audible.
  • Pitch stays locked: by default they also leave Fixed Note, the oscillators' LFO 2 and ModEnv 2 pitch amounts and Pre-Glide alone, and never create, change or remove a mod-matrix routing to an oscillator pitch destination. (An empty mod-matrix slot points at O123Ptch, so a mutated depth alone would transpose the patch.) Existing pitch modulation is kept as it is.
  • Turning the Peak's knobs and buttons updates this editor (CC, 8-bit CC pairs and NRPN, on the editor's MIDI channel). Changes made only in the Peak's menus send nothing, so use Request Current Patch after them, and after changing patch on the Peak. Moving Reverb Type or Size re-reads the patch from the Peak, because each changes the other (not while the Librarian tab is showing, where the reply would be filed in the library).

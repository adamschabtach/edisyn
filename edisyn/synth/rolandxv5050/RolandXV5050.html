Roland XV-5050

This is an editor for the Patch mode of the Roland XV-5050. It edits all 948 bytes of a patch: Patch Common, the MFX / Chorus / Reverb headers, the Tone Mix Table, the four Matrix Controls and the four Tones, and it includes a librarian for the 128 USER patches and the eight preset banks.

The XV-5050 shares Roland's model ID 00 10 with the XV-3080 and XV-5080, so this editor will probably load their patches too. It has only been developed against the XV-5050's documentation.

Before you start

On the synthesizer, set SYSTEM > MIDI&USB > Rx Exclusive to ON and Protect Exclusive to OFF (Owner's Manual p.105). Set Edisyn's Device ID to the number shown as the synth's Device ID, which is 17 by default and may be anything from 17 to 32.

The patch edit buffer the editor writes to only exists in Patch mode, so the editor switches the synth to Patch mode before requesting or sending a patch. If you were in Performance mode, you will find yourself in Patch mode afterwards.

Effects are raw slots for now

An XV-5050 effect is a type number plus 32 (MFX), 12 (Chorus) or 20 (Reverb) general-purpose parameter slots. What each slot means depends on the type, and the Owner's Manual documents the names and value ranges of each effect's parameters without saying which slot holds which. Nothing published, as far as I can tell, closes that gap.

So the MFX and Chorus / Reverb tabs show the effect type by name and then the raw slots, as numbers from −20000 to +20000. Set the type on the synth's own panel, read the patch back into Edisyn, and the slots will hold whatever the synth put there. Editing a slot does what it does. This is unsatisfying but honest, and patches round-trip exactly, so nothing is lost by it. Mapping the slots to named controls means measuring all 90 MFX types on the hardware; that is the next piece of work.

For the same reason, mutation and crossover leave the effect slots alone to begin with, and the three effect type parameters are never mutated at all: changing a type re-interprets every slot under it.

Waves

The Wave L/Mono and Wave R choosers list all 1083 internal waves by name. The stored range runs to 16384, because wave numbers above the internal set belong to SR-JV80 and SRX expansion boards, whose wave names are not in the XV-5050's manual. Such numbers do turn up in the factory patches: user patch 79 carries an SRX wave on a switched-off Tone 3, and another patch an SR-JV80 wave, which is a board the XV-5050 cannot even take.

The editor stores and re-sends those values exactly, so patches round-trip unaltered. It simply cannot put a name to them: the chooser falls back to showing its last entry for a wave outside the internal list. If you fit an expansion board and want its waves named, that needs wave lists from the board's own manual.

Tested against hardware

This editor has been run against an XV-5050 (system version 3.00). All 128 user patches were dumped and every one of them parses and re-emits byte-identically. One request for the whole patch returns all nine blocks, and its data matches nine separate per-block requests. Writing to a user slot stores permanently, verified across a power cycle, with the rest of user memory confirmed unchanged afterwards.

The manual's parameter table held up: control sources are CC numbers with 32 unnamed, patch categories are indices into the list on page 22, and the tempo-synced note values above 127 are in the order given here. Three things did have to change, all of them in this editor rather than the table: wave numbers keep the full range instead of being clamped, writing to stored memory needs about a second to commit, and GM2 turned out not to be downloadable at all.

Still unverified:

  • the librarian's own interface -- bank upload has not been run from Edisyn, which is why librarianTested() still returns false. The protocol underneath it is proven;
  • everything to do with rhythm sets and performances, since those editors do not exist yet.

One thing worth knowing: the patch edit buffer only exists while a patch is selected. If the synth has a rhythm set selected, "request current patch" gets no reply at all and simply times out. Select any patch and it works again.

The Rhythm and Performance editors are not written yet.

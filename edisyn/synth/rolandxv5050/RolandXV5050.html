Roland XV-5050

This is an editor for the Patch mode of the Roland XV-5050. It edits all 948 bytes of a patch: Patch Common, the MFX / Chorus / Reverb headers, the Tone Mix Table, the four Matrix Controls and the four Tones, and it includes a librarian for the 128 USER patches and the eight preset banks.

The XV-5050 shares Roland's model ID 00 10 with the XV-3080 and XV-5080, so this editor will probably load their patches too. It has only been developed against the XV-5050's documentation.

Before you start

On the synthesizer, set SYSTEM > MIDI&USB > Rx Exclusive to ON and Protect Exclusive to OFF (Owner's Manual p.105). Set Edisyn's Device ID to the number shown as the synth's Device ID, which is 17 by default and may be anything from 17 to 32.

The patch edit buffer the editor writes to only exists in Patch mode, so the editor switches the synth to Patch mode before requesting or sending a patch. If you were in Performance mode, you will find yourself in Patch mode afterwards.

Effects are raw slots for now

An XV-5050 effect is a type number plus 32 (MFX), 12 (Chorus) or 20 (Reverb) general-purpose parameter slots. What each slot means depends on the type, and the Owner's Manual documents the names and value ranges of each effect's parameters without saying which slot holds which. Nothing published, as far as I can tell, closes that gap.

So the MFX and Chorus / Reverb tabs show the effect type by name and then the raw slots, as numbers from −20000 to +20000. Set the type on the synth's own panel, read the patch back into Edisyn, and the slots will hold whatever the synth put there. Editing a slot does what it does. This is unsatisfying but honest, and patches round-trip exactly, so nothing is lost by it. Mapping the slots to named controls means measuring all 90 MFX types on the hardware; that is the next piece of work.

For the same reason, mutation and crossover leave the effect slots alone to begin with, and the three effect type parameters are never mutated at all: changing a type re-interprets every slot under it.

Waves

The Wave L/Mono and Wave R choosers list all 1083 internal waves by name. If an SRX expansion board is fitted, its waves are numbered beyond 1083, and this editor clamps them to 1083 when it reads such a patch — it would alter the patch. Patches that use only internal waves are unaffected. Add SRX support before using this editor with a board fitted.

Not yet tested against hardware

Everything here was built from the Owner's Manual and verified offline: the parameter table tiles each block exactly, and patches survive emit → parse → emit byte-identically. None of it has been run against an XV-5050 yet. In particular these are unverified:

  • that one request for the whole patch returns all nine blocks, rather than needing one request per block;
  • the pauses after a patch change, after a Patch-mode switch, and between the nine messages of a patch send;
  • that a write to a USER address stores the patch permanently;
  • the encoding of the control-source lists (MFX Control Source, Matrix Control Source), where the manual's list is one shorter than the stored range and CC32 appears to be a hole;
  • the Patch Category list, and the tempo-synced note values that Tone Delay Time and LFO Rate take above 127;
  • the Wave Group ID the synth reports for internal waves;
  • the GM2 banks' bank-select numbers, which is why the librarian is marked untested.

The Rhythm and Performance editors are not written yet.
